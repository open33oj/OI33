## 本轮修复

### 颜色与主题

- 顶栏/菜单/侧栏/Wiki 链接补充 `:visited`，解决“点过的菜单变灰、未点的仍白色”。
- Wiki 工具栏不再误用 `--oi33-topbar-bg`，改为卡片背景/边框/文字。
- 猫猫广场外壳（工具栏、导航、Tab、大猫侧栏、地图留白、NOTE）接入主题；
  地图/猫像素/奖章数据色保持独立。
- 默认暗色卡片 `#323334` → `#1b1f27`，与外壳统一。
- 亮色预设卡片从接近白色改为可辨识的主题浅色。
- 左侧导航去掉圆角块和竖线，只保留白字 + 强调色图标。
- 卡片圆角 `12px → 2px`；域名标签 `999px → 4px`；收起按钮改为方形。

- 7 个遗漏 `alt` 的头像补 `alt=""`。

### 版式

## 仍存在的问题（非阻塞）

1. 约 21 个 `href="javascript:..."` 仍存在于 core 覆盖模板（讨论、评论、训练、AI 审核、Wiki 删除等）。
   功能正常，但键盘/语义不如 `<button>`，后续逐页替换。
2. 57 个模板仍有页面内 `<style>`，约 60 处 inline 颜色样式（含主题预设色卡）；多数是动态徽章、运势、奖章等级、
   评测状态、代码块或画布色，属于有意保留；新代码应走 `docs/style-guide.md`。
3. 42 个 `<button>` 未显式写 `type`；其中只有两处在表单内：题目上传按钮（默认提交，符合预期）
   和猫猫广场 `<form method="dialog">` 的取消按钮（符合预期）。
4. 猫咪地图、像素画、奖章墙、图表的数据色不跟主题；这是设计边界，不是遗漏。
5. `/oi33/rating` 已弃用并返回 404，README 已标注。
6. 尚未引入浏览器级视觉回归；后续可加 Playwright 截图对比，覆盖亮/暗、桌面/移动。
